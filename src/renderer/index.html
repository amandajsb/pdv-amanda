Sobre o comprovante

Este sistema emite comprovante não-fiscal. O comprovante de venda serve para o cliente conferir a compra, mas não substitui documento fiscal. Se a sua loja é obrigada a emitir NFC-e no seu estado, essa obrigação continua valendo. A emissão de NFC-e está prevista para uma versão futura e o sistema já guarda os dados necessários.
